# myflames 2.1.0 (2026-06-05)

myflames 2.1.0 is a Python command-line tool (Python 3.7 or later, no external dependencies) that turns MySQL and MariaDB EXPLAIN ANALYZE output into flame graphs, other plan views and compact digests for AI agents.

## New features

- Adds exact GPT token counts. `myflames digest --cost --tokenizer gpt` counts tokens for GPT models with tiktoken, which comes with the optional `myflames[gpt]` extra, and needs no API key or network access.

## Improvements

- The `tokens` command is now `digest`, named for what it produces: the compact plan digest you hand to an LLM. `myflames digest plan.json` prints the digest, `myflames digest --cost` shows the token and cost savings report, and `--show` is now `--show-prompts`.
- The `findings` command is now `advise`, a verb that matches `compare`, `check` and `digest`. Its options are unchanged.

## Deprecations and removals

- `tokens` and `findings` remain as deprecated aliases of `digest` and `advise`. They print a one-line notice on stderr, keep their previous behavior (`tokens` still shows the savings report by default) and will be removed in a future release.
- The `--exact` option of the old `tokens` command is removed. Use `--tokenizer claude` instead for exact Claude token counts.
