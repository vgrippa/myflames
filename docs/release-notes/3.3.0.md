# myflames 3.3.0 (2026-10-23)

myflames 3.3.0 is available for macOS on Apple Silicon and, as an unsigned preview, for Windows x64.

## New features

- Adds an unsigned Windows x64 preview of the desktop app. The installer needs no administrator prompt and installs per user. On Windows the app also finds the MySQL and MariaDB clients their installers place under Program Files, which those installers do not add to PATH.

## Bug fixes

- Fixed an issue where command-line commands crashed on Windows when their output was redirected or piped and contained characters outside the ANSI code page, such as query text or table names. Output is now written as UTF-8, and a non-ASCII password given on standard input is no longer changed on the way.
- Fixed an issue where ProxySQL Query digests could not evaluate any rule pattern on Windows and reported every pattern as unknown.
- Fixed an issue where the error log hint for a MariaDB server on Linux lost its `/` path when myflames ran on Windows.
- Fixed an issue where keyboard shortcut hints showed the macOS symbols (⌘K, ⌥⌘R, ⌥⌘I) on Windows and Linux. They now read Ctrl+K, Ctrl+Alt+R and Ctrl+Alt+I.
- Fixed an issue where Windows showed a scroll bar down the whole window. The narrow icon rail also hides its scroll bar on short windows now.

## Known issues

- The Windows build is an unsigned preview: Windows SmartScreen asks before the first run, quitting the app force-stops its backend, and after a crash a statement already running on the server keeps running until it ends.
