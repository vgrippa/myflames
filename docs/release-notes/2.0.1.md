# myflames 2.0.1 (2026-06-05)

myflames 2.0.1 is a Python command-line tool (Python 3.7 or later, no external dependencies) that turns MySQL and MariaDB EXPLAIN ANALYZE output into flame graphs, other plan views and compact digests for AI agents.

## Bug fixes

- Fixed an issue where the main finding followed a fixed category order, so a 50-row scan could headline over a 16,000-row sort. Among scan, sort and temporary table findings, the one that touches the most rows now wins. Join strategy findings still lead when present.
- Fixed an issue where full scans of very small tables were flagged. A scan that touches fewer than about 100 rows in total (rows times loops) is no longer reported, while a small inner table of a large join is still flagged.
- Fixed an issue where scans of derived tables, CTEs and `<temporary>` results were reported as base table full scans. These intermediate results exist only while the query runs and cannot be indexed, so they no longer get a missing-index warning.
- Fixed an issue where a covering index read was reported as use of the `use_index_extensions` optimizer switch. The switch does not show in EXPLAIN, so myflames no longer reports it and shows a plain covering index feature instead.
- Fixed an issue where `index_merge` sort-union plans from MySQL 8.4 were not detected. myflames now recognizes the "Sort-deduplicate by row ID" operation and the `index_merge` access type.
