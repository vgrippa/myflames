# myflames 1.3.0 (2026-04-10)

myflames 1.3.0 is a Python command-line tool (Python 3.7 or later, no external dependencies) that turns MySQL and MariaDB EXPLAIN ANALYZE output into flame graphs, other plan views and HTML reports.

## Release highlights

- Live connection mode runs the plan statement on a MySQL or MariaDB server and renders the result in one step.
- A new environment advisor combines the plan with server settings and schema to give tuning suggestions, each with its reason.
- Every `--output` run writes a JSON sidecar that AI agents, CI dashboards and `jq` can read.
- HTML reports have a new layout with an executive summary, a **Fix first** card and glossary tooltips.

## New features

- Adds live connection mode for MySQL 8.4 and MariaDB 10.11 and 11.4. With the same options as the `mysql` client, such as `-h`, `-u`, `-p` and `-e`, myflames runs `EXPLAIN ANALYZE FORMAT=JSON` on MySQL or `ANALYZE FORMAT=JSON` on MariaDB, collects server details and renders the result in one step.
- Adds SSL support to live mode with the client's `--ssl-mode`, `--ssl-ca`, `--ssl-cert` and `--ssl-key` options. Live mode uses your installed `mysql` or `mariadb` client, so it needs no Python driver and works with the server's authentication plugin. `--mysql-binary` selects a specific client.
- Adds a password prompt to live mode: `-p` with no value asks for the password. myflames passes the password to the client through a temporary option file that only you can read, so it never appears in the process list, the environment or logs, and deletes the file on exit.
- Adds server details to live mode: `SHOW CREATE TABLE` for each table the query touches, table sizes from `information_schema.tables` and the session variables the advisor checks. `--no-collect-schema`, `--no-collect-stats` and `--no-collect-variables` turn each one off.
- Adds an environment advisor with eight rules that compare the plan with the collected settings and schema. It gives copy-paste tuning suggestions for `innodb_buffer_pool_size`, `sort_buffer_size`, `join_buffer_size`, `tmp_table_size` with `max_heap_table_size`, `optimizer_switch` overrides, missing indexes, non-InnoDB tables and `innodb_flush_log_at_trx_commit`.
- Adds detection of non-sargable join conditions, where a function such as `LOWER()`, `CAST()` or `DATE()` wraps a column. No index or buffer setting helps until the condition is rewritten, so it becomes the report's primary action. It works on MySQL hash joins and MariaDB block nested loop joins.
- Adds a JSON sidecar file. Every `--output` run also writes a `.json` file next to the SVG or HTML with plan totals, optimizer switches, warnings, suggestions, an executive summary, the primary action and the collected server details. AI agents, CI dashboards and `jq` can read it without parsing SVG.
- Adds a glossary of more than 30 EXPLAIN and optimizer terms. Each term has a short tooltip, a technical explanation for experienced DBAs and a plain-English explanation for newcomers.

## Improvements

- Improves the HTML report with a new layout. An executive summary and a **Fix first** card sit at the top, jargon terms have glossary tooltips, and every `SET`, `CREATE INDEX` and `ALTER TABLE` suggestion is in a block you can select and copy.
- HTML reports fold warnings, explanations, the collected environment and the raw JSON into sections you can expand. They embed the analysis as JSON-LD for AI agents, use landmarks and ARIA labels for screen readers, and adapt to widths from 720 px to 1400 px.
- Every advisor suggestion now includes a "Why:" explanation of its trade-off, such as an in-memory sort compared with a merge on disk, or the cost of converting a MEMORY temporary table to InnoDB.

## Bug fixes

- Fixed an issue where MariaDB plans lost the join condition of a block nested loop join, which hid non-sargable conditions from the advisor.
- Fixed an issue where standalone SVG files opened in a browser needed horizontal scrolling at the fixed 1800 px flame graph width. Every SVG myflames writes now scales to the window.

## Deprecations and removals

- `-h` now sets the host, as in the `mysql` client, and no longer shows help. Use `--help` for help. `--version` still works.
