# myflames 3.4.0 (2026-11-11)

myflames 3.4.0 is available for macOS on Apple Silicon and, as an unsigned preview, for Windows x64.

## Release highlights

- The **Query editor** adds multiple cursors and suggests the connected server's own keywords, functions, tables and columns as you type.
- Hover over a table or column to see its definition, and get a warning before you run `UPDATE` or `DELETE` without `WHERE`.
- Fixes a window freeze that a statement with many leading comments could cause in **Processlist** or the **Query editor**.

## New features

- Adds multiple cursors, automatic closing of brackets and quotes, and comment and line editing shortcuts to the **Query editor**. Each tab keeps its own undo history, and **Query editor shortcuts** lists the available keys.
- Adds suggestions for the connected server's keywords and functions, schemas, tables, columns, aliases, CTE names and system variables. Accepting a function adds its parentheses, and inside a built-in function call a hint shows which argument you are typing and, when known, how many the function takes.
- Adds details on hover for tables and columns, and warnings for `UPDATE` or `DELETE` without `WHERE`. After myflames has read a database's full table list or a table's column list, it also flags names that are not in it.

## Improvements

- **Settings > Query editor** offers **Multiple cursors**, **Suggestions while typing**, **Close brackets and quotes**, **Wrap long lines**, **Problem warnings** and **Details on hover**, kept on this computer and applied at once.

## Security fixes

- Fixed an issue where a statement with many leading comments could freeze an open myflames window, either when another session's statement appeared in **Processlist** or when it ran in the **Query editor**.
- Fixed an issue where a slow regular expression could freeze **Find** in the **Query editor**. Searches that take too long stop with **Pattern too slow to search**.
- Fixed an issue where a server-controlled name containing right-to-left characters could reorder the suggestion list. Suggestion labels and details now isolate right-to-left text.

## Packaging notes

- The bundled MySQL client is unmodified Oracle code under GPLv2 with the Universal FOSS Exception. Its license ships inside the app, and the GitHub release includes the matching source code (`mysql-8.4.13.tar.gz`).
