# myflames 3.4.3 (2026-11-15)

myflames 3.4.3 is available for macOS on Apple Silicon and, as an unsigned preview, for Windows x64.

## Release highlights

- myflames no longer logs in to saved connections you did not choose: connection groups (**Group** in **Connections**) let you choose which ones **Cluster**, **Replication**, **ProxySQL** and **Readyset** may read together, and myflames recommends groups for connections that share a topology.
- **Cluster** and **Replication** now detect ProxySQL connections and Readyset's helper connections on a MySQL or MariaDB server.

## New features

- Adds connection groups (**Group** in **Connections**) so you choose which saved connections **Cluster**, **Replication**, **ProxySQL** and **Readyset** may read together. A group bar above the topology shows which group members were read and offers **Add to <group>**, **Review…** or **Create a group…** when saved connections share a topology, matched without logging in from connections you have opened.

## Bug fixes

- Fixed an issue where **Cluster**, **Replication**, **ProxySQL** and **Readyset** logged in with saved passwords to up to six other saved connections, including production ones you never chose, to find linked ProxySQL or Readyset servers and replication source versions. Reads now open only saved connections in the same **Group** as the connection in use, and notes about saved connections no longer include SQL or raw error text.
- Fixed an issue where **Cluster** and **Replication** never detected ProxySQL or Readyset clients connected to a MySQL or MariaDB server. ProxySQL connections and Readyset's helper connections are now detected (or reported as unknown when `performance_schema` is off), and not seeing a Readyset connection does not mean Readyset is not connected.

## Packaging notes

- The bundled MySQL client is unmodified Oracle code under GPLv2 with the Universal FOSS Exception. Its license ships inside the app, and the GitHub release includes the matching source code (`mysql-8.4.13.tar.gz`).
