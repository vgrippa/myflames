# myflames 1.0.0 (2025-12-15)

myflames 1.0.0 is a Python command-line tool (Python 3.7 or later, no external dependencies) that turns MySQL EXPLAIN ANALYZE output into flame graphs and other plan views.

## New features

- Adds five views of a MySQL query plan: a flame graph (the default), a bar chart, a treemap, a Visual Explain-style diagram and a collapsible execution tree.
- Adds a **Query Analysis** panel to every view. It warns about full table scans, hash joins, BNL join buffers, temporary tables and filesorts, lists the optimizer features the plan uses, and gives tuning suggestions and heuristic index suggestions with their DDL.
- Adds interactive features: click to zoom, details on hover, search with Ctrl+F, and pinning. The diagram also supports drag to pan, and the execution tree lets you collapse and expand branches.
- Adds support for plans in the newer `query_plan` JSON format, including plans from the hypergraph optimizer.
- Adds the query text to the output. Pass it with `--query` or `--query-file`, or let myflames take it from the EXPLAIN JSON.
- Adds automatic time units: myflames shows milliseconds or microseconds depending on the total query time.
