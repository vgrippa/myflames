# myflames 2.0.2 (2026-06-05)

myflames 2.0.2 is a Python command-line tool (Python 3.7 or later, no external dependencies) that turns MySQL and MariaDB EXPLAIN ANALYZE output into flame graphs, other plan views and compact digests for AI agents.

## New features

- Adds support for MySQL 9.7 plans from both the traditional and the hypergraph optimizer. myflames reads the 9.x `query_plan` format and the new `temp_table_aggregate` and `rows_fetched_before_execution` access types, and detects FirstMatch semijoins in hypergraph plans. Plans from MySQL 8.4 and MariaDB 10.11 and 11.4 work as before.
- Adds support for MariaDB 11.8 `ANALYZE FORMAT=JSON` output, including plans with scans, joins, sorts, semijoins, derived tables and window functions.

## Bug fixes

- Fixed an issue where `myflames tokens --exact` stopped with a `TypeError` when `ANTHROPIC_API_KEY` was not set. It now falls back to the offline estimate with a note on stderr. myflames reads the key from the environment when it runs and never stores it.
