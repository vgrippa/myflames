# myflames 3.4.1 (2026-11-11)

myflames 3.4.1 is available for macOS on Apple Silicon and, as an unsigned preview, for Windows x64.

## Release highlights

- Choose from 17 themes, including three new myflames originals (Fire, Digital Rain and Neon Grid) and popular editor palettes such as Dracula, Nord and Tokyo Night.
- **Settings** opens as a full page, the sidebar can be resized, and your theme, layout and view choices now stay the same after you restart the app.
- **Query editor** suggestions appear as you type, and a selection is easier to see in dark themes.

## New features

- Adds 14 themes beside System, Light and Dark: Fire, Digital Rain, Neon Grid, Dracula, Nord, Solarized Light, Solarized Dark, Tokyo Night, Gruvbox Dark, Catppuccin Mocha, Catppuccin Latte, GitHub Light, GitHub Dark and One Dark. Choose one in **Settings > Appearance**, where each card previews its colors, or type **Theme:** in **Search**. Chart, status and connection colors keep their meaning in every theme.
- Adds [How-to guides](https://myflames.io/docs.html?article=howto) to the documentation, with short recordings that show multiple cursors and other common tasks step by step.

## Improvements

- **Settings** opens as a page with **Appearance**, **Query editor**, **Workspace**, **Updates and news** and **Client tools** sections. Open it from the gear at the bottom of the sidebar, with ⌘, (Ctrl+, on Windows), or from **Search**.
- Drag the sidebar's right edge, or use the arrow keys on it, to make the sidebar wider. Double-click the edge to reset it. The width is kept when you restart the app.
- The version and the update status, with **Check for updates** and **View releases**, now appear at the bottom of every screen.
- **Query editor** suggestions show keywords, functions and names already read from the server as soon as you type. Names that are not read yet join the open list when they arrive, and names already read stay available while they refresh.
- Selected text, other occurrences of a selected word and the current **Find** result are easier to see, in light and dark themes and when the editor is not focused.

## Bug fixes

- Fixed an issue where the theme, the docked **Server** list, the **Health** refresh choice, the inspector width, the **Explain** format and the **File transfer** view choices reset when the desktop app restarted.

## Packaging notes

- The bundled MySQL client is unmodified Oracle code under GPLv2 with the Universal FOSS Exception. Its license ships inside the app, and the GitHub release includes the matching source code (`mysql-8.4.13.tar.gz`).
