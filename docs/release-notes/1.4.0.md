# myflames 1.4.0 (2026-04-23)

myflames 1.4.0 is a Python command-line tool (Python 3.7 or later, no external dependencies) that turns MySQL and MariaDB EXPLAIN ANALYZE output into flame graphs, other plan views and HTML reports.

## New features

- Adds Big O complexity labels to every operator, such as `O(n · log m)` for a nested loop over an indexed table and `O(n + m)` for a hash join. Each label has a severity color and a short rationale, and myflames leaves the label out when it is not sure.
- Adds the labels to every view: a severity dot and a tooltip line in the flame graph, a **COMPLEXITY** column in the bar chart, a chip on larger treemap tiles, and a chip under each access box and join in the diagram. The bar chart column hides on canvases narrower than 900 px.
- Adds a legend for the complexity labels at the bottom of the diagram, bar chart and treemap, so you can read the labels without leaving the page.
- Adds operator complexity to the JSON sidecar file. Each operator with a complexity label gets an entry, and the field is left out when no operator has one.

## Known issues

- Filesort is always labeled `O(n log n)` as a worst case. A sort for a `LIMIT` that uses a priority queue is `O(n log k)`, and myflames does not detect it yet because it does not read the outer `LIMIT`.
- The hash join label does not yet explain whether a particular join spills to disk. Spilling changes the cost constants, not the complexity class.
