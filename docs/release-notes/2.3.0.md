# myflames 2.3.0 (2026-09-30)

myflames 2.3.0 is a Python package (Python 3.7 or later) with a local browser workspace (`myflames ui`) and the command line.

## Release highlights

- `myflames ui` opens a local browser workspace where you import, inspect, compare and save MySQL and MariaDB plans.
- The live query laboratory and the `capture` command run a query with typed parameters, repeat the measurement and record schema, statistics and optimizer traces.
- Visual Explain gains a MySQL Workbench-style rendering of the full plan with join symbols, row arrows, search and export.
- The advisor names the index that lets MySQL skip a filesort for a single-table `ORDER BY`.

## New features

- Adds `myflames ui`, a local browser workspace for MySQL and MariaDB plans. Import files or paste JSON, inspect six chart views and operator details in a persistent inspector, compare plans, and download HTML reports or JSON analysis. The server accepts connections only from your own computer, and `--port` and `--no-browser` set the port and skip opening a browser.
- Adds linked selection across the workspace charts, so an operator selected in one chart is selected in the others. The charts also offer branch focus and collapse, metric bars, shortcuts to bottlenecks and links to the matching Teach lesson.
- Adds saved investigations. Plans you open stay in memory for the page session, and you can save them as local investigations with notes, tags, named experiments and baselines. Investigations export as portable bundles, and connection profiles are saved without passwords.
- Adds a live query laboratory and the `capture` command. Both run a query with typed parameters as an estimated or an analyzed plan, repeat the measurement, and can be canceled or given a time limit.
- Adds captured context to live runs: table and index definitions, statement statistics, changes in session status counters and searchable optimizer traces. When the server cannot provide one of them, myflames says so.
- Adds the `explore` command for working with a plan interactively: select operators, focus or collapse branches, and inspect their metrics.
- Adds a view modeled on MySQL Workbench's visual conventions, in the workspace and as `--type workbench`, and merges it with the Diagram view into one Visual Explain view. It shows operator colors, join symbols, estimated-row arrows and the full plan tree, with pan, zoom, search, node details and SVG or HTML export. Existing `diagram` commands still work.
- Adds Teach to the workspace: a searchable lesson catalog with family filters, interactive lessons inside the page, curriculum navigation and offline HTML downloads.
- Adds an advisor suggestion for the index that removes a filesort. When a single-table `ORDER BY` sorts on plain columns, myflames suggests an ordered or covering `CREATE INDEX` that keeps each column's sort direction, so MySQL reads rows already in order. Joins, aggregates and expression sort keys still get the general sort advice.
- Adds a FirstMatch semijoin lesson. It shows how `WHERE col IN (subquery)` only asks whether a match exists, so the inner scan stops at the first match.
- Adds a browser playground, linked from the README, where you paste a plan and see it rendered without installing anything. It runs the published myflames package in the browser with Pyodide.

## Improvements

- Plan comparisons match operators by plan structure and mark each one as added, removed, changed or uncertain, with a confidence level. A missing timing stays distinct from a measured zero.
- Improves parsing of MySQL plans that have subqueries in the `SELECT` list. Their branches stay in the plan tree.
- Visual Explain draws larger join symbols with Venn diagram regions for the reported join type, such as the whole left circle for a left join. Unknown join types stay unshaded.
- Improves mouse and trackpad zoom, which follows the size of each gesture and coasts to a stop with limited momentum.
- The MCP tool `analyze_plan` returns a compact analysis by default: plan summary, warnings, suggestions, index hints, optimizer switch explanations and the operator tree. Pass `detail="full"` for the complete record. Written sidecar files and `digest` output are unchanged.
- The HTML report's **Fix first** card and `advise` rank suggestions with the same policy, so they agree on the top action. A plan with no findings shows a "No blocking issues found" card.
- The before and after comparison report has the same footer as the main HTML report, with the "Made with myflames" line and the credit to Brendan Gregg and Tanel Poder.
- A simpler stacked-flame logo appears in the workspace sidebar, on the welcome screen and as the browser tab icon.

## Bug fixes

- Fixed several issues in saved investigations and search. The saved investigations heading is aligned, searches show loading and empty states, a clear-search action is available, and optimizer trace search says when nothing matches.
- Fixed an issue where reopening an operator link opened the wrong Teach lesson, and where Teach explanation cards showed literal tags around code.
- Fixed an issue where operator search had no label for screen readers. Estimated comparisons no longer read as if they were measured.
- Fixed an issue where Visual Explain zoom gave no feedback. The view shows the current zoom percentage, reacts when you press a zoom button and disables a zoom direction at its limit. Click the percentage to reset to 100%.
- Fixed an issue where Chrome kept showing the old tab icon after the logo changed, and where workspace tabs opened before a rebuild lost the logo.
- Fixed several Import dialog issues with the file picker overlapping other content, wrapping on narrow screens and scrolling in short windows. Empty drops and canceled file selections no longer reopen the picker.
- Fixed an issue where the search controls in the bar chart and treemap views did not work.
- Fixed an issue where passwords with backslashes or control characters were not escaped in the option file given to the database client. The raw EXPLAIN JSON from the client is kept exactly as returned.
- Fixed an issue where myflames missed table references in SQL whose string literals contain comment markers. MySQL `#` comments and subtraction of negative numbers are handled correctly.
- Fixed an issue where the advisor suggested MRR for primary key ranges and covering index ranges. The suggestion applies only to secondary index ranges.
- Fixed an issue where the advisor used the wrong temporary table size limit. It applies the limit that matches MySQL's TempTable engine, the MEMORY engine or MariaDB. Buffer pool and sort suggestions also say whether they rest on measured evidence or only on configuration.
- Fixed the complexity labels for aggregates. Scalar and streaming aggregates show O(n) with DISTINCT counted separately, and aggregates that have no model show no label.
- Fixed an issue where SQL containing HTML comment markers made the JSON-LD data embedded in HTML reports invalid.
- Fixed bar chart issues where self and total times were converted to microseconds inconsistently and where a shortened annotation could split an XML entity.
- Fixed the exit code for input and output errors when rendering a plan or running `compare`. Both print a diagnostic and exit with code 2.
- Fixed an issue where HTML and JSON comparisons dropped every repeated occurrence of an operator after the first.
- Fixed several lesson playback issues: delays kept running while paused, speed changes did not apply during playback, and seeking resumed the animation from the wrong position.
- Fixed the handling of malformed comparison share links. The teaching explorer also keeps a selection you have explicitly emptied.

## Packaging notes

- The workspace's front-end files ship inside the Python package, so `myflames ui` needs no Node.js.
