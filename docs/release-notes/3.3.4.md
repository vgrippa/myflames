# myflames 3.3.4 (2026-11-10)

myflames 3.3.4 is available for macOS on Apple Silicon and, as an unsigned preview, for Windows x64.

## Release highlights

- myflames now updates itself. Install 3.3.4 by hand once, and later versions download and install from inside the app.
- The desktop app includes the MySQL 8.4.13 command-line client, so you can connect from a computer that has no MySQL installed.
- One rule picks the MySQL or MariaDB client program for each server, and **Settings > Client tools…** shows which program is used and why.

## New features

- Adds automatic updates. With **Settings > Check for updates automatically** turned on (the default), myflames checks for a new version shortly after it opens and once a day after that. **Check for updates** on Home and in **About myflames** checks right away. A badge next to the logo shows the download, and **Restart to update** installs it. On macOS, the app must be in an Applications folder to update itself.
- Adds a bundled MySQL client. The macOS app and the Windows installer include the official MySQL 8.4.13 LTS `mysql` and `mysqldump` programs, so you can connect without installing a MySQL or MariaDB client first.

## Improvements

- **Settings > Client tools…** replaces **Database client…**. For each server, myflames uses the client that matches the server's engine and version, then the nearest newer version, and warns you when it has to fall back to an older one. You can keep **Automatic** or choose an installation, separately for MySQL and MariaDB servers.
- **Maintenance > Tools** shows the program each job uses for the current server, where it comes from and why it was chosen, and lists every copy myflames found with its path.
- New dumps are saved to **Documents/myflames dumps** by default, or to a folder in your home directory when there is no Documents folder. The dump review tells you when Start will create the folder.

## Bug fixes

- Fixed an issue where myflames could not find a MySQL client installed in a common location and stopped with "Cannot find 'mysql' or 'mariadb' on PATH". The search also covers the client that ships with MySQL Workbench on Windows, and on macOS versioned Homebrew formulas such as `mysql-client@8.4`, Laravel Herd and MySQL Workbench.
- Fixed an issue where the app stopped with a command-line error when no `mysql` or `mariadb` client was installed. The view that needs a client explains what is missing and offers **Choose client tools…**.
- Fixed an issue where Dump and Restore showed a greyed-out **Start** button with no reason when no client could run the job. The tab names the missing program instead.
- Fixed an issue where an older installed `mysqldump` was used instead of a bundled copy that matched the server better. SQL restores and CLONE use the client from the selected installation too, and a job refuses to start if the tool changed after you reviewed it.
- Fixed an issue where a MariaDB server on a computer without MariaDB tools used an older installed MySQL client instead of the bundled 8.4.13 client.
- Fixed an issue where a broken client choice for MySQL servers also blocked MariaDB servers, or the other way round.
- Fixed an issue where MariaDB clients received MySQL-only options such as `ssl-mode` and `get-server-public-key`. When a sign-in fails because the client lacks an authentication plugin, the error names the client and the plugin.
- Fixed an issue where Restore offered **New database…** for a dump that creates its own databases and then refused at Start. Restore reads the dump first and offers only the targets that can work, with the reason under the field.
- Fixed an issue where a dump of selected tables could not be restored after its source database was dropped. The restore creates the database first, with the source character set and collation when the dump recorded them.
- Fixed an issue where SQL `INSERT` exports quoted integer and decimal values. When a result comes from plain columns of one table, numbers are written without quotes.
- Fixed an issue where the Query editor offered **Explain analyze** for statements it cannot analyze, such as `SET` and `SHOW`.
- Fixed an issue where the Query editor's **Database** list missed databases created or dropped from the editor.
- Fixed an issue where **Auto-commit** overlapped the Run analysis note in the Query editor toolbar. The toolbar wraps onto a second row when its items do not fit.
- Fixed an issue where starting **Refresh every view** from a view's Refresh menu dropped keyboard focus on the page. Focus moves to the run's **Stop** button.
- Fixed an issue where Home showed "Not checked" next to "In use" for a server whose readiness had not been read. The cell shows a dash, and its tooltip points to **Check now**.
- Fixed confusing counts in the Server views. Indexes says "6 tables read by full scans (3 mostly)" instead of "3 mostly full scans", and Processlist labels its counters **Server-wide** because they include monitoring and background threads.
- Fixed several Maintenance issues. Choosing another database resets the Dump table selection, the Dump and Restore database lists are read again when they open, Upgrade check no longer preselects a target that the installed MySQL Shell cannot check, and **Maintenance > Tools** marks every copy in use.

## Security fixes

- myflames now checks installed client programs before it runs them. On macOS and Linux, a program or folder that other users can change is refused. On Windows, only programs in Program Files or your user profile are used. Refused copies stay in the list with the reason.

## Known issues

- Windows builds are an unsigned preview, so Windows shows an "Unknown Publisher" warning when the installer runs. Until the installer is signed, updates on Windows are verified with the checksum published with each release.
- Starting **Refresh every view** from a view's Refresh menu can still leave keyboard focus on the page after some redraws. Press Tab to reach the toolbar again.
- The bundled MySQL client cannot sign in to MariaDB accounts that use `ed25519` or `parsec`, or to servers that require Kerberos, LDAP SASL, OCI or WebAuthn authentication. Install the MariaDB or MySQL client tools for those servers.

## Packaging notes

- The macOS DMG is about 7 MB larger because it includes the MySQL client.
- The bundled MySQL client is unmodified Oracle code under GPLv2 with the Universal FOSS Exception. Its license ships inside the app, and the GitHub release includes the matching source code (`mysql-8.4.13.tar.gz`).
