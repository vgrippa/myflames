# myflames 1.2.0 (2026-04-09)

myflames 1.2.0 is a Python command-line tool (Python 3.7 or later, no external dependencies) that turns MySQL and MariaDB EXPLAIN ANALYZE output into flame graphs and other plan views.

## New features

- Adds support for MariaDB 10.11 and 11.4. myflames detects MariaDB `ANALYZE FORMAT=JSON` output on its own, and all five views (flame graph, bar chart, treemap, diagram and tree) work with MariaDB plans. Nested loops, filesorts, unions, window functions, materialized subqueries, derived tables, covering indexes and correlated subqueries are handled.
- Adds support for plans of running MariaDB queries. Besides `ANALYZE FORMAT=JSON SELECT ...`, myflames reads the output of `SHOW ANALYZE FORMAT=JSON FOR <connection_id>` and `SHOW EXPLAIN FORMAT=JSON FOR <connection_id>`.
