# myflames 3.2.0 (2026-10-23)

myflames 3.2.0 is available as a desktop app for macOS on Apple Silicon and as a Python package (Python 3.7 or later).

## Improvements

- The macOS app is signed with a Developer ID and notarized by Apple, so it opens from Finder without Control-click or removing the quarantine attribute by hand.
- Durations read as "36 s", "4 min 12 s" or "18 d 12 h" in Processlist, Locks, Transactions, Replication and the Query editor's ALTER review, with the exact seconds on hover. Processlist also shows the server's State in its own column.

## Packaging notes

- The macOS app ships as a DMG, `myflames-3.2.0-macos-arm64.dmg`. Builds you make yourself stay unsigned.
