# myflames 1.1.0 (2026-04-01)

myflames 1.1.0 is a Python command-line tool (Python 3.7 or later, no external dependencies) that turns MySQL EXPLAIN ANALYZE output into flame graphs, other plan views and HTML reports.

## Release highlights

- HTML reports put the interactive plan view, the analysis and export buttons in one self-contained file.
- `myflames compare` reports what changed between a before plan and an after plan.
- myflames installs with `pip install myflames` and has no external dependencies.

## New features

- Adds HTML reports. `myflames --output report.html explain.json` writes a self-contained page with the interactive SVG, an analysis sidebar, summary cards and buttons to export SVG, JSON or a printable PDF. It works with all five views.
- Adds before and after comparison. `myflames compare before.json after.json` writes an HTML report with the change in total time, per-operator changes in self time, rows and loops, full scans that appeared or went away, and warnings that were resolved or are new.
- Adds `myflames guide`, which tells you which view to pick for what you want to learn, such as how time is distributed, which operator is slowest or the join order.
- Adds `-o` (`--output`) to write the result to a file, with an HTML report for paths that end in `.html`, and `--version` to print the installed version.
- Adds a `sample.json` plan in the repository root, so you can try myflames in 30 seconds with `myflames sample.json > query.svg`.
- Adds installation with pip. `pip install myflames` installs the `myflames` command, with no external dependencies.

## Improvements

- Improves diagram zoom with zoom in, zoom out and reset buttons in the bottom-right corner, which replace Ctrl+scroll zoom. Drag to pan and double-click to reset work as before.

## Bug fixes

- Fixed an issue where plans saved from the `mysql` client could not be read without the `-s -r` options. myflames now handles escaped newlines and tabs, the `EXPLAIN` column header, table borders, a UTF-8 byte order mark and warnings before the JSON. When input still cannot be parsed, the error suggests the right options (reported by Anil Joshi).
