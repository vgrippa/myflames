# myflames 3.4.2 (2026-11-15)

myflames 3.4.2 is available for macOS on Apple Silicon and, as an unsigned preview, for Windows x64.

## Release highlights

- Thank you to Acácio Lima Rocha ([@acaciolr](https://github.com/acaciolr)), whose contribution ([#31](https://github.com/vgrippa/myflames/pull/31)) lets **Cluster** switch InnoDB Cluster modes, rejoin members and manage InnoDB ClusterSet through MySQL Shell.
- After a Kill, myflames reads the server again and shows what happened to the transaction, its locks and the sessions it blocked.
- The **Database diagram** zooms with the mouse wheel or trackpad, at a speed you choose.

## New features

- Adds mouse-wheel and trackpad zoom to the **Database diagram**, with a **Diagram wheel zoom speed** setting in **Settings > Workspace** for the diagram and the Mermaid preview.
- Adds a result note after a Kill in **Locks** or **Processlist** with what the server confirms: the statement, transaction and locked rows before and after, whether each blocked session still waits, and about how many changes a rollback still has to undo. The note stays amber until the locks are released.
- Adds InnoDB Cluster mode switches and member rejoin to **Cluster** when MySQL Shell is installed. Switching to multi-primary or single-primary mode (MySQL Shell 8.0 or later) also updates every member's `auto_increment` settings and the cluster metadata, and rejoin (MySQL Shell 8.1 or later) uses incremental recovery only. Contributed by Acácio Lima Rocha ([@acaciolr](https://github.com/acaciolr)) in [#31](https://github.com/vgrippa/myflames/pull/31).
- Adds an InnoDB ClusterSet view to **Cluster**: the primary and replica clusters, invalidated clusters and the replication channel's health, with **Use** to open a saved connection to another cluster's instance. With MySQL Shell 8.0.27 or later, you can switch the primary cluster, fail over to this replica cluster when the primary cluster is lost, and rejoin an invalidated cluster. Contributed by Acácio Lima Rocha ([@acaciolr](https://github.com/acaciolr)) in [#31](https://github.com/vgrippa/myflames/pull/31).

## Improvements

- Mermaid preview wheel zoom follows scroll distance, so small trackpad movements zoom smoothly.
- **Kill connection** shows an amber warning for an open transaction: its uncommitted changes are undone and lost, the rollback can take a long time, the connection keeps its locks until the rollback ends, and the application loses its connection.
- The Kill sheet starts on **Kill connection** when the session is idle or its statement runs inside a longer transaction. **Kill query only** then warns that the transaction and its locks stay open and the blocked sessions keep waiting.

## Bug fixes

- Fixed an issue where **Kill connection** was refused while a transaction showed ROLLING BACK after **Kill query** stopped its statement. The transaction stays open with its locks in that state, which can last a long time after a large statement.

## Packaging notes

- The bundled MySQL client is unmodified Oracle code under GPLv2 with the Universal FOSS Exception. Its license ships inside the app, and the GitHub release includes the matching source code (`mysql-8.4.13.tar.gz`).
