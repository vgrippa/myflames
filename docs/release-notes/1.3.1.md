# myflames 1.3.1 (2026-04-13)

myflames 1.3.1 is a Python command-line tool (Python 3.7 or later, no external dependencies) that turns MySQL and MariaDB EXPLAIN ANALYZE output into flame graphs, other plan views and HTML reports.

## New features

- Adds interactive lessons that animate how MySQL works inside: B-tree index lookup, Block Nested Loop, hash join, a join algorithm comparison and the LRU buffer pool cache. Each lesson has a scrubber, pause and speed controls, an interactive complexity chart and real SQL examples, and rendered copies are on the project's GitHub Pages site.

## Improvements

- Improves the Visual Explain diagram with a hotspot layer in the viridis heat-map palette. Hotspots are marked with borders only, and text keeps WCAG-compliant contrast.

## Deprecations and removals

- Removes the four legacy scripts in the repository root: `mysql_explain.py`, `mysql_explain_bargraph.py`, `mysql_explain_flamegraph.py` and `stackcollapse_mysql_explain_json.py`. Use the `myflames` command, which replaced them in 1.0.
